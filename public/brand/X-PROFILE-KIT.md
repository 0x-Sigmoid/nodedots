# NodeDots X profile kit

Ready-to-use drafts for [@nodedots](https://x.com/nodedots). These assets and
posts have been prepared, not uploaded or published to the account.

## Profile fields

- Display name: **NodeDots**
- Handle: **@nodedots**
- Website: **https://nodedots.com/waitlist**
- Avatar: `public/brand/x-avatar.png` — 400 × 400.
- Header: `public/brand/x-cover.png` — 1500 × 500.
- Location: leave blank unless the owner supplies a public location.
- Category, if using a professional profile: choose a relevant software or technology category available in X.

## Five starter posts

### 1. Why we're building it

```text
A diff tells you what changed. It doesn't always tell you what was left behind.

We're building NodeDots Code to review a pull request in the context of the rest of your repo, with evidence and a checklist before merging.
```

### 2. Authentication example

```text
You replace Firebase Auth with Clerk. Login works. Billing still looks up the old Firebase ID.

That's the kind of missed connection we're exploring with NodeDots Code. See the illustrative review:
https://nodedots.com/
```

### 3. Account-deletion example

```text
The account-deletion button works. The database row is gone.

What about the Stripe customer, uploaded files, and active sessions?

NodeDots looks for what a change forgot. Join the early-access waitlist:
https://nodedots.com/waitlist
```

### 4. Invite the conversation

```text
What's the most surprising side effect you've found after merging a pull request?

An old API assumption? A missing migration? A test nobody thought to add?

We're building NodeDots Code around those moments. Tell us your story.
```

### 5. The wider vision

```text
Code is our first focus. We're also exploring how NodeDots could bring clearer evidence to applications, contracts, research, and decisions.

These are future directions, not released services. Explore the vision:
https://nodedots.com/vision
```

## Publishing sequence

1. Upload the avatar and header; inspect desktop and mobile crops.
2. Set the display name, bio, and website field.
3. Publish the pinned post with its image and alt text, then pin it.
4. Add the first reply and publish starter posts when there is something useful to discuss.

No launch date, pricing, language support, customer count, affiliation, or
security claim is implied. Announce these only after owner confirmation.

X recommends 400 × 400 profile photos and 1500 × 500 headers:
[X profile customization guide](https://help.x.com/en/managing-your-account/how-to-customize-your-profile).

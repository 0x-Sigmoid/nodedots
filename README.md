# NodeDots

Personal developer portfolio for thoughtful web products built around learning, clarity, trust, and practical user experience.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run build
```

## Notes

SEO, sitemap, robots, web manifest, JSON-LD, and `llms.txt` are included.
